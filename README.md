## 从阅读体验，到开放生态

### [开元阅读 · Origo X](https://github.com/miloquinn/origo-x)

**从分页、排版到批注，打磨一本书在屏幕上的每一页。**

基于 Flutter / Dart 的跨平台阅读器。公开源码版围绕本地阅读展开：TXT / EPUB 导入、原生分页、翻页模式、字体与主题、书签笔记、全文搜索及系统 TTS。产品官网和正式发行版提供完整的产品入口。

### 让生态里的工具彼此连接

| 项目 | 我在解决的问题 |
| :--- | :--- |
| **[ORSP · 开放书源协议](https://github.com/miloquinn/origo-source-protocol)** | 用统一 HTTP 协议连接阅读器与独立内容服务。提供协议规范、JSON Schema、OpenAPI 和参考服务，让接入有标准可循。 |
| **[ORSP Converter](https://github.com/miloquinn/orsp-converter)** | 把书源 JSON 规则转换为 ORSP 服务端点；支持批量转换、逐项验证和失败重试，让协议真正落地。 |
| **[Niki AI](https://github.com/miloquinn/Niki-AI)** | 把 Claude Code 放进 Obsidian 侧边栏，让 AI 在笔记工作流中直接协助写作与编辑。 |
| **[Origo API](https://github.com/miloquinn/Origo-API)** | 基于 New API 定制的自托管 AI 网关：统一模型接入、管理控制台、计费展示及开发工具配置。 |
